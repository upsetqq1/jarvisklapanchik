# Юра — desktop-прототип

Первый прототип проверяет прозрачное окно Windows, перетаскивание картинки, клик по персонажу и пропуск кликов через прозрачные области. Анимации, голос и OpenAI пока не подключены.

## Запуск

```powershell
npm start
```

Картинка лежит в `yura-transparent.png`. Чтобы заменить временное изображение, положите новый PNG с альфа-каналом под этим именем. Исходная присланная картинка сохранена как `yura.png`.

## Управление

- Перетащите персонажа мышью.
- Нажмите на непрозрачную часть изображения, чтобы открыть панель.
- Кнопка «Закрыть Юру» завершает приложение.

## Заметки

- Для прозрачных областей используется проверка альфа-канала картинки и переключение режима пропуска мыши Electron.
- Поведение кликов, фокус и размещение поверх окон нужно проверить на рабочем столе Windows; оно зависит от системного окружения и конфигурации мониторов.
- Позиция окна пока не сохраняется.
